# 簡単セットアップGUI監査（2026-09-21）

目的: 「何もない状態からGUIの簡単な操作だけでYMM4が開けるか」の精査。
方法: 保存設定を退避→クリアしたフレッシュ状態でv1.0.4ホストを日英起動・
目視、全停止メッセージの実走・目録化、コード監査。終了後に保存設定を復元済み。

## 操作フロー（GUIだけで完結することの確認）

1. 同意トグルON → 「互換環境を一括インストール」押下
2. ZIP選択パネル（`.zip` 限定）→ メディアフォルダ選択パネル（新規作成可）
3. 長時間の自動工程（状態欄に120秒ごとの進捗行）
4. 「1. 設定を確認」→「設定OK」→「2. YMM4をMacで開く」
5. YMM4側の初回ダイアログ（更新確認など）を進める → メインウィンドウ

2のファイル選択前にRosetta判定が走るよう本セッションで修正（後述B）。
3の多重起動（終了→再開→再押下）の同時実行はfail-closed設計で破壊は
起きないが、時間の無駄になる（後述C・今回は見送り）。

## 停止メッセージ目録（すべて正確な対処付きであることを確認）

| 状況 | 表示 | 対処の有無 |
|---|---|---|
| Rosetta未導入／破損 | `softwareupdate --install-rosetta --agree-to-license`（日英） | ○ コマンド明示 |
| build前提不足 | `Missing build prerequisites: ...`＋`brew bundle --file=...` またはHomebrew導入手順 | ○ 実走確認（exit 2・download前） |
| Metal compilerなし | `xcodebuild -downloadComponent MetalToolchain` | ○ |
| 空き容量不足 | `need about 10 GiB`＋`nothing was downloaded` | ○ |
| リネームZIP | 公式ファイル名のまま選択するよう表示 | ○ |
| 未検証ZIP | SHA-256付きで導入拒否 | ○ |
| 起動時Rosetta破損 | Rosetta再導入コマンド | ○ |
