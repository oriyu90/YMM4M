# Legal boundaries

YMM4M is independently developed interoperability software. Investigation is limited to public documentation, public plugin APIs, file metadata, PE headers, dependency manifests, runtime logs, and black-box comparison with a lawfully obtained copy.

The project does not redistribute YMM4, its branding, proprietary Microsoft runtimes or fonts, CrossOver, or third-party plugins. Do not commit those files. Do not decompile YMM4 implementation code without a separate explicit legal review.
