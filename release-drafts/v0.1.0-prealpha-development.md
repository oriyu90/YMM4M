# YMM4M 0.1.0 pre-alpha 3 development preview

This is an unpublished development preview. It is not a release-ready
distribution.

- `YMM4M-0.1.0-prealpha3-development-adhoc.dmg`
- SHA-256:
  `33248b15eae13b1d7a87b4fbeb90145e6d77461963ebb86d2bfd9996b7adabfe`
- Size: 529,913 bytes
- Bundle version: 3
- Host architecture: ARM64
- App signature: explicit ad-hoc bundle signature
- TeamIdentifier: not set
- Notarization/stapling: not performed
- Gatekeeper release assessment: rejected, as expected for this development

The DMG contains only the app, an Applications symlink, the development warning,
the Mac setup guide, and the MIT license. The app contains bootstrap scripts,
the pinned input lock, and source patches. It does not contain YukkuriMovieMaker4,
Wine/DXMT binaries, CrossOver, Microsoft runtimes/fonts, plug-ins, or test media.

## What changed in build 3

- Added a one-confirmation setup that fetches pinned HTTPS source archives,
  verifies SHA-256 and archive paths, builds Wine/DXMT, clean-stages the runtime,
  and creates the dedicated WPF-profiled Wine prefix.
- Enabled FreeType in Wine using pinned 2.14.3 headers and creates a prefix-local
  Japanese Noto OTF without relying on host-installed fonts.
- Added the tested Direct2D Premultiply implementation to the recorded Wine
  patch and fixed Wine service shutdown during prefix setup.
- Normalized Wine PE source/build paths. Independent roots now produce
  byte-identical `d2d1.dll` and `dwrite.dll`, retaining strict whole-file hashes.
- Clarified the setup UI and Mac guide: automatic paths need no normal manual
  selection; the user only supplies the official YMM4 executable afterward.
- Sealed the completed app bundle with an explicit ad-hoc signature and verifies
  it before DMG creation.

## Current verified development gates

- Swift build and contracts pass, including validation of the final clean
  runtime.
- Python unit tests pass 16/16; the 20-feature compatibility registry validates.
- Two independent Wine PE build roots produce byte-identical patched D2D/DWrite
  modules.
- A newly built runtime and newly created prefix pass all eight Win32 fixtures,
  including compute 100/100, D2D Premultiply/3D transform, Japanese pixel output,
  and shared/isolated font fallback.
- DMG checksum, read-only mount, bundle signature, ARM64 architecture, and
  forbidden-payload scan pass.

## Important limitations

- Direct YMM4 Japanese IME remains unsupported; the tested native overlay is a
  version-scoped workaround.
- Windows-reference comparison, audible playback, a licensed supported
  VoiceItem workflow, effects/media completeness, drag-and-drop, and clipboard
  tests remain incomplete.
- The Win32Service crash is not yet assigned or fixed.
- Required long-duration soak, fault injection/recovery, update state machines,
  and clean-machine/hardware matrix tests remain incomplete.
- No Developer ID signing is available. This artifact cannot be notarized or
  treated as a normal end-user macOS release.
- Local runtime generation is validated, but redistribution of that generated
  runtime is not authorized by this draft.

The deferred release-time license audit remains unopened because the final
release gates are incomplete. This draft must not be published as-is.
