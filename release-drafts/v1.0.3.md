## Changes since v1.0.2 (see CHANGELOG.md 1.0.3 section)

- Functional Rosetta 2 availability check (real x86_64 execution, not the
  oahd marker) in the host probe, at the start of the one-shot setup, and in
  the bootstrap preflight — fixes "setup completes but YMM4 will not open"
  after the macOS 27 upgrade wipes Rosetta.
- DXMT Metal-shader compiler detection with a process-local DEVELOPER_DIR
  fallback to installed Xcode.app; exact install remedy otherwise.
- DXMT Unix library pointed at the system C++ runtime (`install_name_tool`,
  loader path only) so `winemetal.so` loads on macOS 27; fail-closed residual
  check.
- macOS 27 joins macOS 26 as a validated host (`HostCompatibility` 26/27).

No runtime, patch, fixture, or catalog behavior changed. Pinned bootstrap
sources and hashes are identical to v1.0.2, so no staged runtime needs
re-validation.
