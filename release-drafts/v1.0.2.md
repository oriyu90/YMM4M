## Changes since v1.0.1 (see CHANGELOG.md 1.0.2 section)

- Brewfile ships inside YMM4M.app; setup remedy points at the exact copy.
- Preflight: `flex` covered, Homebrew-missing remedy first.
- Free-space gates (~10 GiB full / ~2 GiB prefix-only) before any download.
- Liveness heartbeat for long silent steps; host forwards `[gate]` too.
- Whitespace-safe compile-cache fallback with `YMM4M_COMPILE_CACHE_ROOT` override.

No runtime, patch, fixture, or catalog behavior changed. Pinned bootstrap
sources and hashes are identical to v1.0.1, so no staged runtime needs
re-validation.
