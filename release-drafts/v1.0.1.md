# YMM4M v1.0.1 (release draft)

**EXTERNAL_ONLY** maintenance release of YMM4M's own MIT software.
Ad-hoc signed, not notarized (Developer ID unavailable).

## Artifact (filled at packaging time)

- `YMM4M-1.0.1-arm64.dmg` (+ `YMM4M-1.0.1-checksums.txt`, `YMM4M-1.0.1-manifest.json`)
- Bundle 1.0.1 (build 14), ARM64, `LSMinimumSystemVersion` 26.0
- License: `LEGAL-AUDIT-v1.0.1.md` (addendum; incorporates v1.0.0 by reference)

## Changes since v1.0.0

- Fully bilingual (Japanese/English) core diagnostics (`CoreLanguage` /
  `CoreMessages`, `message(for:)`); error cases and APIs unchanged.
- Runtime-URL availability: dead Internet Archive mirrors demoted to
  documentation-only; `--check-urls` probes effective download candidates
  only (scheduled CI gate is green again).
- Rosetta execution-probe fallback (`arch -x86_64 /usr/bin/true`) plus an
  `arch` preflight with a bilingual launch error.
- Non-blocking untested-OS notice on macOS majors other than 26.
- `tools/build-release-dmg.sh` takes version/notice/audit arguments
  (defaults preserve the 1.0.0 invocation).

No runtime, patch, fixture, or catalog behavior changed. Pinned bootstrap
sources and hashes are identical to v1.0.0, so no staged runtime needs
re-validation.

## Verification (this machine: Apple M1 Max, macOS 26.5, CLT-only, no full Xcode)

- `swift build`, `swift run YMM4MContractTests` (incl. 5 new bilingual/Rosetta/host tests)
- `python3 -m unittest discover -s tests/unit` (incl. 2 new mirror/check-urls tests)

- `bootstrap-wine-dxmt-runtime.sh --accept-third-party --plan` and `--check-urls` (exit 0)

- DMG checks: read-only mount, strict ad-hoc signature, ARM64, catalog

Full log: `evidence/v1.0.1-audit-fixes-2026-09-11.md`.
