# YMM4M v1.0.0

First tagged release. **EXTERNAL_ONLY**: this distributes YMM4M's own MIT
software only. YMM4, Wine, DXMT, fonts, LLVM, and CrossOver are never bundled —
YMM4M downloads the pinned build inputs onto your Mac, with your consent, and
builds them locally. You supply the official YukkuriMovieMaker4 ZIP yourself.

## Artifact

- `YMM4M-1.0.0-arm64.dmg` (about 0.8 MB). The exact SHA-256 and size are in
  `YMM4M-1.0.0-checksums.txt` / `YMM4M-1.0.0-manifest.json`, attached to the
  GitHub release, and in the release body. `hdiutil` embeds timestamps, so the
  image is not byte-reproducible across builds; verify against the published
  checksum.
- Bundle: version 1.0.0 (build 13), ARM64, `LSMinimumSystemVersion` 26.0
- Signature: explicit ad-hoc; TeamIdentifier not set
- Notarization / stapling: not performed (no Apple Developer ID)

The DMG contains only `YMM4M.app` (its Swift binary, the bootstrap / stage /
prefix / gate shell scripts, `bootstrap.lock.json`, the four Wine/DXMT patches,
the eight compatibility gate fixtures, and the compatibility catalogue) plus
`READ-ME-FIRST.txt`, `LICENSE.txt`, `LEGAL-AUDIT-v1.0.0.md`, and the setup
guide. It contains no YukkuriMovieMaker4, Wine/DXMT/font/LLVM binaries,
CrossOver, Microsoft runtimes/fonts, plug-ins, voice engines, or media.

## Highlights

### Portability (§4.1 案3)

- `RosettaWineBackend.validateCleanRuntime` accepts **schema-2** runtime
  manifests. Instead of matching one of a few audited whole-file PE hashes, a
  schema-2 runtime must attest — and the app re-checks — that every file matches
  its recorded SHA-256, the build used exactly the pinned bootstrap sources and
  the four patches, the 8-fixture + compute-100 gate passed against *these*
  binaries, and the recorded `winemac.so` loadable-image hash matches the file.
  The schema-1 audited-variant path is unchanged, so existing verified runtimes
  keep working.
- MinGW GCC is no longer pinned to an exact patch level (fails fast below major
  13, warns outside 15–18; the fixture gate is authoritative).
- `runtime/bootstrap.lock.json` is schema 2 with verifiable `mirrors[]` per
  source; `download()` falls through them, `--check-urls` probes every host, and
  a scheduled CI job tracks upstream availability. New
  `tools/validate-bootstrap-lock.py`.

### Runtime / setup

- `WINEDEBUG` defaults to `-all` (verbose tracing is opt-in via
  `YMM4M_WINEDEBUG`).
- Removed the never-buildable `wined3d-vulkan` / `wined3d-opengl` UI profiles.
- `LSMinimumSystemVersion` / `Package.swift` platform set to macOS 26.
- The bootstrap preflight collects every missing prerequisite at once; new
  `Brewfile` (`brew bundle --file=Brewfile`).

### UI

- Full Japanese / English localization of the setup window
  (`app/YMM4M/App/Localization.swift`), compile-time-checked for parity.

### Audit / docs

- `LEGAL-AUDIT-v1.0.0.md` resolves every prior `UNKNOWN` for the DMG contents.
- `docs/WIN32SERVICE_INVESTIGATION.md` and `docs/GPU_EXPECTATIONS.md` record the
  static analyses (no launch-path behaviour changed for either).

## Verification

- Swift build + `YMM4MContractTests`: pass (adds a schema-2 provenance/gate
  test — happy path plus six rejections — and a quiet-`WINEDEBUG` test).
- Python unit tests: 25/25 (adds `test_runtime_gate.py`).
- `validate-runtime-lock` / `validate-compatibility` / `validate-bootstrap-lock`:
  pass. Compatibility registry: 20 features.
- App launches cleanly in both `ja` and `en` locales.
- Release DMG: `hdiutil verify` + read-only mount, ad-hoc signature, ARM64,
  bundle-version 1.0.0, forbidden-payload scan (no `.exe`/`.dll`/`.ttc`/`.otf`/
  YukkuriMovieMaker/CrossOver binaries): pass.

## Known incomplete (disclosed; not blockers for this EXTERNAL_ONLY build)

- No Developer ID signature or notarization. Use Apple's per-app "Open Anyway".
- Windows-reference frame/audio comparison, the full Tier A editing/playback
  matrix, `Win32Service.exe` crash-impact confirmation, GPU Metal-work tracing
  across a full session, and a clean-machine hardware matrix.

Any future release that bundles a prebuilt Wine/DXMT runtime must first close
those gates and redo `LEGAL-AUDIT` for the bundled binaries.
